# 网页版服务端部署

Qecho（题鸣）的同一套 Go 引擎既可作为桌面端的本地 sidecar，也可直接部署到服务器，用浏览器访问。
网页版与桌面端共用全部接口、数据库结构与权限模型。

## 1. 模式差异

| | 桌面端 | 网页版服务端 |
| --- | --- | --- |
| 启动方式 | Tauri 自动拉起 sidecar | 手动 / systemd 启动 |
| 参数 | `--desktop`，动态端口 | 不带 `--desktop`，固定端口 |
| 登录 | 回环地址可用 `local` 空密码 | 用户名 + 密码，需先注册 |
| 前端 | 壳内加载 | `--web-dir` 指向 `dist/` 由引擎托管 |

`--desktop` 仅允许来自回环地址的 `local/空密码` 登录。**反向代理部署时不要加 `--desktop`**，
否则代理转发的本机请求也可能被当作本机登录。

## 2. 构建

```powershell
# 前端静态文件 → dist/
pnpm install --frozen-lockfile
pnpm build

# 引擎（Windows 可交叉编译 Linux）
cd engine
go build -trimpath -ldflags "-s -w -X main.version=1.0.0" -o quizbox-engine ./cmd/engine
```

Linux 部署也可在服务器上直接 `go build`，或用
`GOOS=linux GOARCH=amd64 go build ...` 交叉编译。

## 3. 启动

```bash
./quizbox-engine \
  --host 0.0.0.0 \
  --port 54310 \
  --data-dir /var/lib/quizbox \
  --web-dir /opt/quizbox/dist
```

- `--data-dir`：SQLite、日志、备份所在目录，需可写。
- `--web-dir`：前端构建产物目录；设置后由引擎托管网页版（`/`、`/e/<token>`）。
- `--port 0`：动态端口（桌面端用法，服务端不要用）。

首次启动后打开站点，**第一个注册的账号会自动成为管理员**，之后的注册用户均为普通用户。
建议部署完成后立即注册管理员，再关闭公开注册入口或控制访问。

## 4. systemd 示例

`/etc/systemd/system/quizbox.service`：

```ini
[Unit]
Description=Quizbox engine
After=network.target

[Service]
Type=simple
User=quizbox
Group=quizbox
WorkingDirectory=/opt/quizbox
ExecStart=/opt/quizbox/quizbox-engine --host 127.0.0.1 --port 54310 --data-dir /var/lib/quizbox --web-dir /opt/quizbox/dist
Restart=on-failure
RestartSec=3

[Install]
WantedBy=multi-user.target
```

```bash
sudo useradd -r -s /usr/sbin/nologin quizbox
sudo mkdir -p /var/lib/quizbox && sudo chown -R quizbox:quizbox /var/lib/quizbox
sudo systemctl daemon-reload
sudo systemctl enable --now quizbox
```

监听 `127.0.0.1` 时由反向代理对外，更安全；局域网直连可监听 `0.0.0.0`。

## 5. HTTPS 反向代理（Nginx）

```nginx
server {
    listen 443 ssl http2;
    server_name quiz.example.com;

    ssl_certificate     /etc/letsencrypt/live/quiz.example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/quiz.example.com/privkey.pem;

    client_max_body_size 50m;   # 题库导入上传

    location / {
        proxy_pass http://127.0.0.1:54310;
        proxy_set_header Host              $host;
        proxy_set_header X-Real-IP         $remote_addr;
        proxy_set_header X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 120s;
    }
}

server {
    listen 80;
    server_name quiz.example.com;
    return 301 https://$host$request_uri;
}
```

引擎会读取来自回环地址的 `X-Forwarded-For` 作为客户端 IP，用于登录限流。

外联考试链接按当前访问域名生成（`https://quiz.example.com/e/<token>`），参与者可直接用手机打开。

## 6. 数据与备份

- 数据库：`<data-dir>/quiz.db`（WAL 模式，另有 `quiz.db-wal`、`quiz.db-shm`）。
- 日志：`<data-dir>/logs/engine-YYYYMMDD.log`。
- 备份需同时包含 db + wal + shm，或使用 SQLite 在线备份：

```bash
sqlite3 /var/lib/quizbox/quiz.db ".backup '/var/backups/quizbox-$(date +%F).db'"
```

- 完整性校验：`./quizbox-engine --verify-db /var/lib/quizbox/quiz.db`，输出 `ok: user_version=N`。

## 7. 安全清单

- 不要对公网暴露 `--desktop` 模式。
- 登录接口按 IP 限流（10 次 / 5 分钟），注册按 IP 限流（5 次 / 10 分钟）；注册需通过图片验证码（5 分钟有效、一次性）。公网部署仍建议尽快创建管理员账号。
- 会话 token 存在浏览器 `localStorage`，通过 HTTPS 访问以免被中间人截获。
- 引擎自身不做 TLS 终止，请始终置于 HTTPS 反向代理之后。
- `X-Shutdown-Token` 仅在桌面端注入；服务端未设置时关闭接口返回 404。
