# 题鸣 Qecho 使用手册

题鸣是一款题库练习与考试工具，有桌面版和网页版两种形态：桌面版装在本机，题库、练习记录、错题、考试与成绩全部保存在本机，不需要联网；网页版把同一个引擎部署到服务器，浏览器直接访问、多账号共用一份数据库。桌面版基于 Tauri 2 + Go 引擎 + SQLite。

- 适用版本：0.2.5
- 详细设计见 [题鸣详细设计文档.md](题鸣详细设计文档.md)
- 服务器/网页版部署见 [服务端部署.md](服务端部署.md)

## 1. 安装与启动

1. 运行安装包 `Qecho_0.2.5_x64-setup.exe`，按向导完成安装。
2. 从开始菜单或桌面图标启动「Qecho」。
3. 首次启动会自动初始化数据库与本机管理员账号，无需登录即可进入主界面。
4. 关闭窗口默认最小化到系统托盘；可在「设置 → 关闭窗口时」改为直接退出。从托盘菜单可重新打开窗口或彻底退出。

数据默认保存在 `%APPDATA%\com.quizbox.desktop`，升级或卸载程序不会主动删除该目录，请自行备份。

## 2. 界面导航

左侧导航依次为：

| 页面 | 用途 |
| --- | --- |
| 概览 | 题量、练习与考试概况、快捷入口 |
| 题库 | 题库与题目管理、导入导出、标签管理 |
| 练习 | 按条件组卷作答、继续未完成练习 |
| 考试 | 创建外联考试、分享链接、查看与导出成绩 |
| 错题本 | 复习答错题目、单题重练、移出错题 |
| 统计 | 答题量、正确率、趋势与标签正确率 |
| 设置 | 外观、账号、备份、诊断与关闭行为 |

右上角显示当前账号；网页版登录后可退出，桌面端使用本机账号。

## 3. 题库与题目

### 3.1 新建题库

1. 进入「题库」，点击「新建题库」，填写名称与说明。
2. 管理员还能把题库设为公共题库：公共题库所有登录用户可见，且只有管理员能修改。普通用户建出的题库默认是自己私有的。
3. 普通用户默认**没有**新建题库的权限，需要管理员在侧边栏「用户管理」里勾选「建题库」后才能创建；未授权时「新建题库」按钮为灰色。
4. 题库列表按「全部 / 我的 / 共享给我 / 公共」分组，每行显示题量、练习正确率、最近一次练习时间与归属（我的 / 共享 · 可编辑 / 共享 · 只读 / 公开 · 只读 / 公共）。

### 3.2 共享题库

在题库列表点该行的「共享」（仅所有者与管理员可见），或进入题库详情页点右上角「共享」，可以：

- **可见范围**：选「仅共享成员」时只有所有者与下方成员能看到；选「所有登录用户（只读）」时全站用户都能看到并练习，但只有所有者与共享成员能改内容。
- **共享成员**：搜索用户名后添加，级别分两种——「只读」只能看和练习，「可编辑」还能增删改题目、导入题目；两者都不能改题库信息、删除题库、管理标签。
- 移除成员或改级别即时生效，无需重新登录。

公共题库没有共享设置，由管理员直接维护。题目与练习记录仍归各自账号，共享不会改变练习、错题本与统计的归属。

### 3.3 新建与编辑题目

在题库详情页点击「添加题目」，支持：

- 题型：单选题、多选题、判断题；选项 2–8 个。
- 答案：单选/判断选择一个，多选选择多个。
- 解析、难度（1–5 五档，界面显示为简单 / 较易 / 中等 / 较难 / 困难）、标签（最多 10 个，每个不超过 20 字）、来源（可选，记录题目出处，随导出写入「来源」列）。
- 题图：题干与每个选项都可上传图片，支持 PNG / JPEG / WebP / GIF，单张不超过 8 MB；相同内容自动去重，删除题目不会误删仍被其他题目引用的图片。

题目列表支持按关键词、题型、难度、标签筛选，并可按创建时间或难度排序。

### 3.4 标签管理（题库所有者与管理员）

在题库详情页点击「标签管理」（所有者与管理员可见），可对本题库用到的标签：

- **重命名**：改名后所有关联题目同步更新，不允许与现有标签重名。
- **合并**：把来源标签下的题目转到目标标签，再删除来源标签；合并到自身会被拒绝。
- **删除**：只解除标签与题目的关联，不会删除题目。

标签在各题库间共享；统计页「标签正确率」按标签汇总作答与正确次数。

## 4. 导入题库

进入题库详情页点击「导入题目」，支持 Excel（.xlsx / .xlsm）与 CSV。

0. **下载模板（可选）**：导入弹窗内点「下载导入模板」，得到含两行示例的 xlsx，按列填写后直接导入；桌面端会弹系统保存对话框。
1. **选择题库与文件**：文件上传后自动解析，可在预览里切换工作表与表头行。
2. **核对列映射**：系统按表头自动识别题型、题干、选项、答案、解析、难度、标签、题干图片、来源等列，识别错的可在下拉里手动改；合并选项列（如 `A. … B. …`）与分列选项二选一。
3. **题图关联**：如果「题干图片」列填的是文件名（如 `q1.png`），点击「选择题图文件」一次性选中随包图片。导入时按文件名自动关联，大小写不敏感；未匹配到文件的题目仍会导入，并在预览中提示缺失数量，答题时显示占位图。一次最多 300 张，不符合格式或超过 8 MB 的图片会被忽略。
4. **重复与错误**：重复题可选「跳过」或「保留」；错误行会给出原因，并可下载错误明细 CSV。
5. **确认导入**：导入后显示成功/跳过/失败统计。7 天内在导入批次里可整批撤销（仅限未再编辑的题目）。

提示：CSV 请使用 UTF-8 编码保存，避免中文乱码。

## 5. 导出与分享

- **导出 Excel**：题库详情页「导出」生成 xlsx，包含题型、题目、题干图片、选项、答案、解析、难度、标签、来源，可直接再导入。导出时难度写为 1–5 的数字；导入时数字与「简单 / 较易 / 中等 / 较难 / 困难」两种写法都认。
- **导出题图 ZIP**：把题库引用到的图片整体打包下载，文件名与「题干图片」列一致，便于随题库分发。
- **桌面保存位置**：桌面端导出时会弹出系统保存对话框；网页版直接下载到浏览器默认目录。

## 6. 练习

1. 进入「练习」，点击「开始练习」。
2. 选择题库（可多选）、标签（可多选，匹配任一标签）、题型、难度，可分别打乱题目与选项顺序。标签下拉会列出所选题库实际用到的标签及题量。
3. 「题序范围」可限定只练某一段（如 `51`–`100`），不必每次都从第一题开始。起始题留空按第 1 题算、结束题留空表示练到末题；下方会显示当前筛选共多少道、本次实际练哪一段。范围对「随机」与「按题序」都生效：随机模式是在这段范围内先切段再乱序，不会抽到范围外的题。随机模式在范围行末尾还有「题量」下拉，可选「全部 N 道」或指定题数，填了范围后自动跟随。若同一题库已有按题序的练习记录，还会出现「上次练到第 N 题，从第 N+1 题接着练」的快捷入口。「最近练习」里也会标注每组的范围（如 `按题序 51–100`）。
4. 作答：单选点击即判分；多选选择后点「确认答案」；每题作答后显示正确答案与解析，错题自动进入错题本。
5. 答题卡显示每题对错、标记与当前题；可标记题目、上一题/下一题跳转。
6. 每次作答、当前题号、标记与单题用时都会自动保存。中途关闭应用后，可在练习页「最近练习」里继续未完成的记录。
7. 点击「完成练习」交卷，按各题用时合计显示练习时长与正确率。

### 6.1 键盘快捷键（练习）

| 按键 | 作用 |
| --- | --- |
| `A`–`H` 或 `1`–`8` | 选择对应选项（单选立即判分） |
| `Enter` | 已作答时进入下一题；多选选好后确认答案 |
| `←` / `→` | 上一题 / 下一题 |

输入框聚焦或弹窗打开时快捷键自动失效。

### 6.2 智能答疑（可选）

答完一题后，解析区右上角会出现「问 AI」按钮。点击后右侧答题卡让位给 AI 聊天面板（带滑入动画，不遮挡窗口按钮），自动把这道题发给 AI 分析；点左下角「收起 AI」或面板旁的「收起 AI」按钮即可回到答题卡。

**配置（设置 → 智能助手）**

两条通道**二选一生效**，配置各自独立保存，来回切换互不覆盖：

- **BIC-QA（数据库智能问答）**：填入自己的 `sk-` 开头 API Key（在 [BIC-QA](https://www.bic-qa.com) 个人中心申请），服务地址默认 `https://api.bic-qa.com`，一般无需修改。
- **通用大模型（OpenAI 兼容）**：在「服务商」下拉选择通道，通过「快捷填充」一键填入常见服务商（阿里云百炼 · 通义千问 / DeepSeek / 智谱 GLM / 月之暗面 Kimi / 硅基流动 / 阶跃星辰 / 基元律动 / OpenAI），再补上自己的 API Key 即可；也可手动填任意 OpenAI 兼容地址（服务地址填到版本段为止，末尾的 `/chat/completions` 由程序补全）。

配置好后点「测试连接」验证；打开「启用」开关并保存。**每个账号配置自己的凭据**，互相看不到、也用不到别人的；Key 只存在本机数据目录 `bicqa/user-<id>.json`（0600），不写数据库、不随备份导出，界面只显示掩码。未配置或关闭时不会出现「问 AI」按钮，也不会有任何外部请求。

**面板行为**

- 聊天式布局：你的提问靠右（主色气泡），AI 回答靠左（卡片气泡，含 Markdown 表格与代码块）。
- 首问自动发送（题干 + 选项，不含正确答案与解析），追问直接输入即可（如「这个选项为什么错」「给个 SQL 例子」），同一道题内保持多轮上下文。
- **会话常驻**：收起面板不会丢失记录，正在输出的回答会在后台继续写完；同一道题重新打开接着聊。切到别的题目再切回来，之前题目的记录也能找回（最近 20 题）。切换题目后首次打开会对新题自动发问。
- 长提问默认折叠三行，点气泡本身可展开/收起全文。
- **回答长度可切换**：底部「简答 / 详答」开关，默认简答（约 200 字，一般 10–20 秒返回）；详答逐项展开、补充知识点，通常 30–90 秒。选择会被记住。
- **等待期间能看到模型的思考过程**：实时滚动显示推理文字并计时；正文开始后自动收起，点「展开」可回看。回答过程中可随时「停止」。
- 面板标题显示当前生效的服务商（如 BIC-QA、DeepSeek、阶跃星辰），一眼确认走的是哪家。

## 7. 错题本

- 答错自动收录，记录累计答错次数与连续答对次数。
- 连续答对达到阈值（默认 2 次，可在设置中调为 1–10）后自动移出，并标记为已掌握。
- 支持待复习 / 已掌握筛选、分页、展开查看选项与解析、单题重练以及手动移出。

## 8. 外联考试

### 8.1 创建考试

在「考试」页点击「新建考试」，填写：

- 考试名称、选择题库、抽题数量（1–500）。
- 考试时长（1–360 分钟）、考试密码（至少 4 位）。
- 开考时间段：只能在时间窗内进入考试。
- 可选打乱题目顺序与选项顺序；选项乱序后仍按选项内容判分。

### 8.2 分享链接

创建后点击「分享设置」获取局域网链接 `http://<本机IP>:<端口>/e/<token>`，可一键复制。首次分享时 Windows 可能弹出防火墙提示，点击「允许访问」或使用页面上的「放行防火墙」按钮；未放行时其他设备打不开链接。参与者需与本机在同一网络。

### 8.3 参与者作答

参与者在手机或电脑浏览器打开链接，填写姓名、学号/工号与考试密码后开始答题：

- 支持选择选项（单选/多选/判断），键盘 `A`–`H` / `1`–`8` 选择，方向键切换题目。
- 作答自动保存，断线或刷新后可继续作答；到时自动交卷，服务端判分。
- 主机端「成绩」抽屉可查看每位参与者的状态、得分、作答进度与交卷时间。

### 8.4 导出成绩单

「成绩」抽屉底部左侧显示「共 N 人参加 · 已交卷 M 人」，右侧是「导出 Excel」与「刷新」，固定在底部，名单再长也不用滚到最后。

导出的 xlsx 内容：

- 首行合并标题「考试名 · 成绩」，居中加粗；第二行表头冻结。
- 列：序号、姓名、学号/工号、状态、得分、作答（如 `20/20`）、开始时间、交卷时间、用时（分钟）。
- 用时由交卷时间减开始时间算出，尚未交卷的留空。
- 文件名形如 `考试名-成绩-20261104.xlsx`，非法字符自动换成下划线。

桌面端会弹出系统保存对话框，网页版直接下载。导出是整场考试的全部参与记录，不受界面筛选影响；只有管理员或该考试的创建者可以导出。

## 9. 统计

统计页支持近 7 天 / 近 30 天 / 全部三个范围，展示：

- 答题量、正确率、练习次数、考试次数、考试平均分。
- 日趋势图与题库正确率排行。
- 标签正确率：按标签统计作答次数与正确率，便于定位薄弱知识点；没有标签数据时显示提示。

## 10. 数据备份与恢复

在侧边栏「数据备份」中：

- **立即备份**：手动创建包含数据库与题图的 zip 备份。
- **自动备份**：每日首次启动、导入前、数据库升级前、恢复前自动备份；每日保留 7 份、导入前 5 份、升级/恢复前各 3 份，自动备份合计超过 2 GB 时清理最旧。
- **恢复**：选择备份点「恢复」，应用先校验完整性与版本，并自动备份当前数据；确认后重启应用完成替换。恢复准备就绪到重启前，应用不再写入新数据；如启动失败会自动回退到原数据库。

## 11. 设置

| 分组 | 内容 |
| --- | --- |
| 外观 | 深色模式 |
| 账号安全 | 修改密码（当前密码 + 新密码 8–72 位；本机账号未设密码时当前密码可留空） |
| 本地引擎 | 引擎运行状态、版本、端口与数据目录 |
| 练习与复习 | 默认题量、题目/选项乱序、错题掌握阈值 |
| 诊断 | 诊断日志抽屉：查看内存日志（最近约 400 行）、复制全文；完整日志按天存放在数据目录 `logs/` |
| 关闭窗口时 | 最小化到托盘 / 直接退出 |
| 关于 | 版本与项目信息 |

管理员侧边栏还有两个独立页面（普通用户看不到入口）：

- **用户管理**：查看账号、状态、注册时间与最近登录；设为管理员/普通用户；授予「建题库」「导出导入」权限；重置密码（重置后该用户需用新密码重新登录，已登录会话失效）；停用/启用账号（停用立即使其会话失效，数据保留可恢复）；删除账号（需先停用，删除前自动备份，个人题库一并删除、其外联考试关闭）。
- **数据备份**：手动备份、备份列表、恢复与删除，以及自动备份保留份数（见第 10 节）。

说明：本机账号（用户名 `local`）固定为管理员，不能改角色、重置密码或被删除；系统始终保留至少一名管理员，且不能删除当前登录的账号。当前登录账号不能修改自己的角色。

普通用户的「建题库」「导出导入」是管理员逐个授予的授权位（管理员始终具备）。新增用户默认两项都没有：能练习、能考试、能管理共享给他的题库内容，但不能新建题库、不能导出或导入题目。

## 12. 账号与权限

- **桌面端**：默认使用本机账号自动登录；可在设置里为它设置密码，用于网页版或重新登录。
- **网页版**：支持注册 / 登录，注册需填写图片验证码；首个注册用户自动成为管理员。
- 管理员可管理公共题库、标签、全部用户与全部题库；普通用户默认只能访问自己的题库与被共享的题库。
- 题库按三级校验：**可读**（练习、查看题目）、**可改内容**（增删改题目、导入）、**可管理**（改名、删除、共享、管理标签）。所有者与管理员拥有全部三级；共享成员按「只读 / 可编辑」获得前两级。
- 普通用户默认不能新建题库、不能导出导入题库，由管理员在「用户管理」中勾选授予；删除账号会连带删除其个人题库并关闭其外联考试（删除前自动备份，可在「数据备份」页找到 pre-delete 备份）。

## 13. 常见问题

**页面提示“引擎未启动”或无法进入？**
桌面端请重启应用；若仍失败，到「设置 → 诊断日志」复制日志反馈。网页版请确认引擎进程与端口正常。

**局域网设备打不开考试链接？**
确认双方在同一网络、链接中的 IP 为本机局域网 IP，并在 Windows 防火墙中放行对应端口（可用分享面板的放行按钮）。

**题图显示“图片缺失”？**
图片文件可能被手动删除或未随导入一起提供。本次导入可在导入预览里重新选择图片；已入库题目可在编辑页重新上传。

**忘记密码？**
普通用户可请管理员在「用户管理」中重置；本机账号可在设置中直接修改（当前密码留空）。网页版最后一个管理员无法被降级。

**数据在哪里？升级会丢吗？**
默认在 `%APPDATA%\com.quizbox.desktop`，升级安装不会删除数据。建议定期在「数据备份」页备份，并把备份 zip 复制到其他磁盘。

**CSV 导入中文乱码？**
请用 Excel「另存为 → CSV UTF-8」或文本编辑器以 UTF-8 保存后再导入。

## 14. 卸载

通过 Windows「应用和功能」卸载 Qecho。卸载默认保留数据目录；如需彻底清除，请手动删除 `%APPDATA%\com.quizbox.desktop`（请先确认已备份需要保留的题库）。
